# Live Narration Engine

Design notes and build prompts for a domain-agnostic live narration engine, with cricket as its first domain.

## Project status

This repository currently contains planning documents only; there is no runnable implementation yet. The latest build direction is in [`prompts/narration-engine-v2-ontology-prompt.md`](prompts/narration-engine-v2-ontology-prompt.md). The earlier discussion notes capture the initial structured-feed concept, while [`prompts/commentary-engine-prototype-prompt.md`](prompts/commentary-engine-prototype-prompt.md) explores a video-first prototype. The architecture diagram illustrates the video-ingestion and narration pipeline.

## Local media

Match videos and generated audio are ignored by Git. Keep media out of the repository unless you have the rights to redistribute it; use an appropriately licensed sample or a separate authorized storage location for testing.
